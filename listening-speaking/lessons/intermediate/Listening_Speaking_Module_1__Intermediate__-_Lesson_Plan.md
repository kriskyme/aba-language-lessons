## Task Levels for this plan (Intermediate band)

Per the Lesson prompt's Section 0.1 Task Levels by Band table, Intermediate's task Levels are **2, 3, 4, 5**
(extension-down: 2; native: 3, 4; extension-up: 5) - 4 task Levels, so every lesson carries 4 differentiated task
Levels. The real source itself is calibrated to Level 3 (Intermediate's lower/native level: 2-4 minute runtime,
near-natural but clear pace, per Section 0.2).

Quoted verbatim from `learningobjectives.csv` (Module 1: Describing, Listening/Speaking modality), split into the
Listening half (governs Day 1 tasks) and Speaking half (governs Day 2 tasks):

| Level                    | Listening (Day 1 basis)                                                                                                                                                                                                                                                    | Speaking (Day 2 basis)                                                                                                                                                                                 |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 2 (extension-down)       | "Can listen to one short spoken description using a fixed frame ('It is \_\_\_.') supported by visuals, and identify the described object among 2-3 choices."                                                                                                              | "Can produce one sentence describing a familiar object using the memorized frame with one open slot, prompted by the teacher."                                                                         |
| 3 (native, anchor level) | "Can listen to a short spoken description using a two-slot frame ('It is **_ and _**.') and identify the described object among a small set of choices, with a model available for reference."                                                                             | "Can describe a familiar object using the memorized frame with two open slots, with a model available rather than being prompted step-by-step."                                                        |
| 4 (native)               | "Can listen to a short spoken description of a familiar object, choosing their own connectors, and identify its features, one comparison, and the brief reason given for that comparison."                                                                                 | "Can produce a short original description of a familiar object including one comparison and a brief reason for it, choosing their own connectors, working independently."                              |
| 5 (extension-up)         | "Can listen to an extended spoken description of a familiar or semi-familiar place or object, summarize how it's organized, and identify one clearly evaluative word choice that signals the speaker's opinion even though the speaker never states the opinion directly." | "Can give an extended description, organizing details logically and including at least one clearly evaluative word choice that signals an opinion without stating it outright, working independently." |

**Note for Step 2 (lesson generation):** Levels 2-3's fixed-frame ("It is **_.") requirement is a real mismatch
with authentic native-speaker audio, which never talks in memorized frames. At generation time, the lowest task
Levels' tasks should ask students to *extract* information into that frame (e.g., "Complete: It is _** and \_\_\_,"
using words drawn from what the real speaker actually says), not expect the source itself to be spoken in a
fixed frame - the same way Passage Reading's lowest task Levels work from the same shared text as everyone
else but with heavier scaffolding, not a simplified text.

## Topic grounding

Every topic below points to a real, findable category of source (a real bakery, market, craft, museum, or
landmark video) rather than a generic invented scene, per the Intermediate-and-up grounding rule. These are
search directions, not confirmed sources - the actual video/audio for each lesson is found and verified against
Section 0.1-0.3 of the Lesson prompt at Step 2, so no specific title, channel, or speaker is named here.
Deliberately avoids overlapping Passage Reading's own Module 1 Intermediate topics (a Puglia kitchen, Yoyogi
Park, running shoes, a Wynwood mural), since a student could plausibly be in both tracks at once.

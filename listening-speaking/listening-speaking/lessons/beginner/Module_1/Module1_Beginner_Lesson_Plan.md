## Task Levels for this plan (Beginner band)

Per the Lesson prompt's Section 0.1 Task Levels by Band table, Beginner's task Levels are **1, 2, 3**
(native: 1, 2; extension-up: 3) - 3 task Levels, so every lesson carries 3 differentiated task
Levels (Beginner is the only band with 3, not 4, since Level 1 is the scale's floor and the band
doesn't also extend a Level down). The real source itself is calibrated to Level 1 (Beginner's
lower/native level: 30 second - 2 minute runtime, graded-for-absolute-beginners register, strong
visual support, per Section 0.2).

Quoted verbatim from `learningobjectives.csv` (Module 1: Describing, Listening/Speaking modality),
split into the Listening half (governs Day 1 tasks) and Speaking half (governs Day 2 tasks):

| Level                    | Listening (Day 1 basis)                                                                                                                                                            | Speaking (Day 2 basis)                                                                                                                    |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 1 (native, anchor level) | "Can recognize familiar single words or fixed phrases in a teacher's oral description and respond by pointing to or naming the matching image."                                 | "Can produce single words or fixed phrases to label a familiar object when prompted."                                                  |
| 2 (native)                | "Can listen to one short spoken description using a fixed frame ('It is ___.') supported by visuals, and identify the described object among 2-3 choices."                       | "Can produce one sentence describing a familiar object using the memorized frame with one open slot, prompted by the teacher."          |
| 3 (extension-up)         | "Can listen to one short spoken description using a two-slot frame ('It is ___ and ___.') and identify the described object among a small set of choices, with a model available for reference." | "Can describe a familiar object using the memorized frame with two open slots, with a model available rather than being prompted step-by-step." |

**Note for Step 2 (lesson generation):** unlike Intermediate/Advanced, Beginner's Level 1 source is
itself a graded, scripted-for-learners clip in simple language, so the fixed-frame extraction task
at Levels 2-3 is a natural fit here rather than a workaround for a mismatched authentic-native-pace
source the way it is at higher bands.

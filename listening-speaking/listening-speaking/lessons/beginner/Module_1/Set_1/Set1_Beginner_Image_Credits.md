# Listening/Speaking - Beginner Module 1 Set 1 - Image Credits

Every image embedded in this Set's student packets, one table per lesson. All are Wikimedia Commons files,
fetched and cited at generation time per `shared/Program_Conventions.md` §I; each lesson `.md` carries the same
citation at the point of use, and this document is where the credits are published. Packets print no credit
(`shared/Student_Packet_Style_Guide.md` §F). Asset files live in the named lesson's own folder.

All three are museum object photographs, chosen so the three garments are told apart by **outline
alone** - a full-length dress on a mannequin, a jacket on a hanger, a brimmed hat - because Style
Guide §A.2 forbids an item answered by reading a chromatic colour off a printed picture and every
packet prints in grayscale. Each was rendered to greyscale and checked before use. This is the one
lesson in the Set where that rule was load-bearing: its planned vocabulary theme was originally
"Colors & shapes." The packet embeds a downscaled copy of each (800px long side, ~30 KB) as a
base64 data URI; the full-size asset stays in the lesson folder.

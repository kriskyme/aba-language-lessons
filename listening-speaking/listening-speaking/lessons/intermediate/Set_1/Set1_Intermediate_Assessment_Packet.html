Speaking Task: Module 1 Set 1 Assessment

Topic: describe and compare two rooms in your home (or two places you know well), and explain the order in which you would show a visitor around them.

Speaking Task ★

Target length: 30-45 seconds.

  1. 1.
    Describe each of your 2 rooms. Say one thing about each room using "It is ___." (2 sentences total.)
  2. 2.
    Then say "First I would show you ___. Then I would show you ___." (Fill in both blanks.)

Before you submit, check:

  • Both rooms described using the fixed frame
  • Clear, correctly ordered sequence using "First...then..."
  • Clear, understandable pronunciation of the target words

Speaking Task ★★

Target length: 45-60 seconds.

  1. 1.
    Describe each of your 2 rooms using the frame "It is ___ and ___." (2 filled frames total.) Use the model card if you need it.
  2. 2.
    Then describe the order you would show a visitor around, using at least 2 order words (first, then, after that).

Before you submit, check:

  • Both rooms clearly described in the two-slot frame
  • At least 2 sequence words used, in a clear order
  • Ideas flow as connected sentences, not isolated words

Speaking Task ★★★

Target length: 60-90 seconds.

  1. 1.
    Describe at least 2 features of each room/place, in your own words (4 features total).
  2. 2.
    Include 1 comparison between the two, with a stated reason.
  3. 3.
    Explain the order you would show a visitor around, using at least 2 of your own order words (not the fixed frame).

Before you submit, check:

  • Clear comparison with a specific stated reason
  • Varied sequence connectors used accurately, not the fixed frame
  • Mostly your own original language, not a memorized frame

Speaking Task ★★★★

Target length: 90-120 seconds.

  1. 1.
    Describe at least 3 features of each place you know well (6 features total), organized (for example, by size, use, or atmosphere).
  2. 2.
    Include at least 1 comparison between the two places with clear reasoning.
  3. 3.
    Explain a visitor's route using at least 3 varied order words (don't repeat the same one).
  4. 4.
    Use at least 1 word that shows your opinion of one place over the other without saying that opinion directly (for example, "cozy" vs. "cramped").

Before you submit, check:

  • Clearly organized comparison, sustained across both places
  • Evaluative word used, without stating the opinion directly
  • Sequence language and comparison language work together smoothly

Per the Lesson prompt's Section 0.1 Task Levels by Band table, Advanced's task Levels are **4, 5, 6, 7**
(extension-down: 4; native: 5, 6; extension-up: 7). The real source is calibrated to Level 5 (Advanced's
lower/native level): 5-8 minute runtime, natural native pace, standard (not learner-simplified) TED Talk,
NPR/BBC feature, or interview, per Section 0.2.

Quoted verbatim from `learningobjectives.csv` (Module 1: Describing, Listening/Speaking modality):

| Level                    | Listening (Days 1-4 basis)                                                                                                                                                                                                                                                               | Speaking (Days 5-8 basis)                                                                                                                                                                                                                                                                                                                            |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 4 (extension-down)       | "Can listen to a short spoken description of a familiar object, choosing their own connectors, and identify its features, one comparison, and the brief reason given for that comparison."                                                                                               | "Can produce a short original description of a familiar object including one comparison and a brief reason for it, choosing their own connectors, working independently."                                                                                                                                                                            |

| 7 (extension-up)         | "Can listen to two extended spoken descriptions of the same subject, critically assess how each speaker's rhetorical choices shape a different impression, and identify at least one unstated interest or assumption behind one speaker's framing that neither speaker states outright." | "Can deliver a well-structured spoken description that deliberately selects and emphasizes detail to shape listener perception, self-monitoring and smoothly repairing at least one imprecise word choice mid-delivery, using idiomatic vocabulary and flexible register control."                                                                   |

**Note for Step 2 (lesson generation): Level 7's Listening objective genuinely requires TWO real sources on the
same subject**, unlike Levels 4-6 which work from the single shared main source. The same issue came up in
Passage Reading's own Advanced-band plan (Level 7 there needed a second comparison text). I've suggested a
natural second-source angle per lesson below (typically an official/promotional framing vs. an independent
one) - not mandatory, just a starting point; both sources still need to be real and verified per Section 0.3,
which roughly doubles the sourcing work for each lesson's Level 7 task specifically.

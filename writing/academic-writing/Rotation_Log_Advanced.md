**Scenario:** **My Last Meal, then A Meal That Went Wrong.** Practice event the last thing the student
made to eat, written from memory (Lessons 1-2 and the Mentor Ladder); draft event one time making or getting
something to eat did not go as planned, the dish circled from a printed list of eight (instant noodles, rice,
eggs, soup, pasta, a sandwich, curry, pancakes), introduced at Lesson 2 Day 2 and written about in Lessons 3-4.
Named reader Mina, a friend who wants to make the same thing and is sure it is simple, whose likely reaction
carries Level 6's required feature. Closing Transfer Check on a third subject, one thing that happened with the
student's own water bottle or cup. Nothing is inherited from Module 1.

**Grammar Focus (A/B):** Focus A: reported speech and thought in narrative (backshift; the say / tell /
ask patterns and which takes a person object; reporting verbs that carry the narrator's attitude: admitted,
insisted, muttered, decided, promised, complained; reported thought as the same structure turned inward) /
Focus B: non-finite openers for pacing (participial and time-phrase sentence openers with the comma that
follows), deliberately non-finite to stay clear of Intermediate Module 2's finite time clauses and Module 1's
concession subordinators; confusable pair said / told. Level 4's own Module 2 row folded in as light content
(student-chosen time connectors, one outcome, a brief reason). Anchored at Level 5's row, Advanced's native
Paragraph Composition Level, and **retained unchanged from the superseded paired plan**: the de-pairing changed
the Scenario, not the grammar.

**Essay Focus (Levels 6-7):** anchored at Level 6's row with Level 7 additive. Because the Set is
standalone and drafts a whole essay, it carries **Essay Focus A as new content** (the reaction-essay shape, hook
types in a narrative form, the introduction's connecting sentences with the thesis last, the conclusion's closing
moves) and **re-anchors Essay Focus B** (topic sentence and support, the thesis line) inside Lesson 1's model
analysis rather than re-teaching it. The reflective turn is this Set's own structural point.

**Real-world writing form:** Module 2's own row, not Module 1's inherited comparison essay. Levels 4-5 a personal
narrative / journal entry in chronological prose with time connectors; Levels 6-7 a **reaction essay** (narrate,
then reflect). 0.9 flags the reaction essay as its loosest mapping, so this Set is its first real test.

**Notes on the standalone shape.** Lesson 1 opens on a fresh hook and carries this Set's only Mentor Ladder
presentation, complete at every Level (a standalone Set has no second look). Lesson 2 Day 2 is real prewriting.
Lesson 3 drafts a complete piece, which at Levels 6-7 restores the full 300-450 and 450-650 word budgets into one
drafting lesson. Peer Editing moves to Lesson 4 Day 1 (Lesson prompt 0.6's standalone placement) and Lesson 4
publishes. The separate Module N+1 verb task is **dropped**: it existed only because a Pair's shared piece keeps
Module N's genre, and this Set's piece is already in Module 2's own.

**Rotation checks run at plan time (Conventions §F), the first time this Set has had one.** As Pair position 5 it
never ran one, by design. Cross-Module against Advanced Module 1 Set 1: no repeat on the Focus pair, the
confusable pair, the Scenario subjects, or the form; Module 1 is descriptive and spatial, this Set narrative and
temporal, and nothing is inherited. Cross-Band by date against every Band file, including the two most recent
(Proficient Module 2 Set 1 and Beginner Module 2 Set 1, both 2026-09-10, both Narrating): grepped for reported
speech, backshift, participial, non-finite, and said / told, with no prior hit anywhere in the program, and for
meal, cook, noodles, food, and kitchen, confirming the field is unspent. **Three near-collisions ruled out

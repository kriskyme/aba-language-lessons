respectively. An earlier version of this note (v2.6-era) said these protocols were no longer the program's

Concentric Circles are fully valid at this program's actual class size (8-12 students), provided every seat has an
explicit, active task and 2-3 discussion prompts are rotated through rather than one static prompt for the full
window. Lessons 1, 2 (Jigsaw), and 4 were checked against this on 2026-09-01: Lesson 1's Fishbowl and Lesson
2's Jigsaw were patched in place (an outer-circle tally task added to Lesson 1; a third discussion prompt split
across Lesson 2's mixed groups), while Lesson 4's Concentric Circles needed no change - it already rotated two
prompts and needs no outer-circle task by design. Only each lesson's Phase 3 section changed; see each
lesson's own doc for the full patch note.

**Protocol and hook names made room-neutral (2026-09-10).** Quality Standards §D11 retired every hook and
protocol that required rearranging the room. The table rows above carry the new names, and all four affected
lessons were rewritten to match in the same pass: Lesson 1's Fishbowl became a **Panel Round** (speakers take
turns from their seats, listeners keep the same tally task), Lesson 4's Concentric Circles became **Rotating
Partners** (find a new partner per prompt) and its Four-Corner Debate became **Take a Side** (the four options
printed in the packet and circled, with a show of hands for the board tally), and Lesson 2's hook was renamed
K-W-L Walk -> **K-W-L Chart**, which is a rename only: it already built the chart on the board with nobody
leaving their seat. The old-to-new mapping is in Listening/Speaking's `Rotation_Log.md`.

**What shapes this Module at this Band:** both Level 2 and Level 3 are fixed-output Reading rows here (a
one-slot frame matched to an image, a two-slot sequential frame matched to a picture pair), so §0.11 and Quality
Standards §D10 govern two Levels in every lesson, and each lesson needs three or four real action photos - 13 in
all, rowed into `Set1_Intermediate_Image_Credits.md`, each chosen for an action that survives grayscale (Style
Guide §A.2).

Sequence and Outcome set rather than the prompt's "Cause & Effect" label (Module 3's verb; already logged as the

expression of that rule yet.

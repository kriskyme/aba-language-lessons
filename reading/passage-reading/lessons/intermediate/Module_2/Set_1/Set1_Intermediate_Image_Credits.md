# Passage Reading - Intermediate Module 2 Set 1 - Image Credits

Every image embedded in this Set's student packets, one table per lesson. All are Wikimedia Commons files,
fetched and cited at generation time per `shared/Program_Conventions.md` §I; each lesson `.md` carries the same
citation at the point of use, and this document is where the credits are published. Packets print no credit
(`shared/Student_Packet_Style_Guide.md` §F). Asset files live in the named lesson's own folder.

This Set needs more images per lesson than Module 1 did: in Module 2 both Level 2 and Level 3 are fixed-output
Reading rows that end in matching a decoded frame to a picture or a picture pair, so every lesson carries three
or four action photos rather than one. Photos are chosen for an action that stays legible in grayscale, never
for colour (`shared/Student_Packet_Style_Guide.md` §A.2).
